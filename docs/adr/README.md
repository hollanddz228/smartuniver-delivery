# Шешімдер журналы (Architectural Decision Records Register)

Бұл құжатта «SmartUniver» жобасы бойынша қабылданған барлық стратегиялық, әдістемелік және архитектуралық шешімдер тіркеледі.

| ID | Тақырыбы | Мәртебесі | Күні | Негізгі шешім |
| :--- | :--- | :--- | :--- | :--- |
| **[ADR-001](ADR-001-delivery-model.md)** | Жобаның жеткізу моделін таңдау (Delivery Model) | **Қабылданды (Accepted)** | 2026-09-22 | Гибридті жеткізу моделі: Discovery → Delivery (Сыртта фикс мерзім, ішінде 2 апталық Scrum спринттері) |
| **ADR-002** | Университеттің ескі серверімен интеграциялық протоколды таңдау (REST API vs SOAP) | *Ұсынылды (Proposed)* | 2026-09-29 | Discovery фазасының нәтижесі бойынша анықталады |
| **ADR-003** | Мобильді әзірлеу стегін таңдау (Flutter vs React Native) | *Жоспарлануда (Draft)* | 2026-10-06 | Команда құзыреті мен кросс-платформалық қолдауды бағалау |

---

### Шешім мәртебелерінің мағынасы:
* **Proposed (Ұсынылды):** Талқылау сатысында, пікірлер жинақталуда.
* **Accepted (Қабылданды):** Бекітілді және жобада міндетті түрде қолданылады.
* **Rejected (Қабылданбады):** Балама нұсқалар пайдасына бас тартылды.
* **Superseded (Ауыстырылды):** Ескірді, орнына жаңа ADR қабылданды.
