> **Пән:** АТ-жобаларды басқару (IT Project Management)

* **Таңдалған жеткізу моделі:** **Гибридті модель (Hybrid: Discovery → Delivery)**

## 🎯 Бағалау критерийлерінің орындалуы (Критерии оценки)

| Бағалау критерийі (Слайд 38) | Орындалу дәлелі | Құжат сілтемесі |
| :--- | :--- | :--- |
| **Артефакт: үш кейс бойынша кесте + ADR-001 + тірі жұмыс кеңістігі** | Толық орындалды | Word есебі + GitHub тақтасы |
| **ADR-де қабылданбаған нұсқалар мен шешімнің салдары бар** | 2 қабылданбаған нұсқа және Trade-offs нақты көрсетілген | [ADR-001](docs/adr/ADR-001-delivery-model.md) |
| **Жұмыс кеңістігі «әдепкі бойынша» жасалмаған, жобаға бапталған** | Кастом өрістер (Priority, Story Points, Stream), арнайы статустар енгізілді | [GITHUB_PROJECT_SETUP.md](docs/GITHUB_PROJECT_SETUP.md) |
| **Кейстер кестесінен қай өлшем шешуші болғаны көрінеді** | 6 өлшемдік кестеде шешуші факторлар айқын белгіленді | Word құжаты (1-бөлім) |
| **Атау келісімі жазылған және алғашқы тапсырмаларда сақталып жатыр** | Тапсырмалар `[FEAT]`, `[TASK]`, `[SPIKE]` префиксімен бапталды | [NAMING_CONVENTIONS.md](docs/NAMING_CONVENTIONS.md) |
